## 维护约定

产品约定描述需要保持的行为；架构说明描述当前实现和代价；协议说明描述接入依据及未验证项；验收报告记录具体版本的测试事实。实现与约定有差异时应明确记录差异并处理，不能通过改写验收结论或删去要求掩盖问题。

修改服务定义、权限、连接生命周期或构建运行方式时，同步更新对应说明与验证结果。证据中的端口、IP、测量值和恢复状态只属于记录当时，不作为下一次运行的默认配置。

历史原始JSON作为独立协议夹具保持原样。新测试结果写入验收证据目录，并在验收报告中说明环境、时间与验证边界；不得用历史记录代替当前实现的实机测试。
